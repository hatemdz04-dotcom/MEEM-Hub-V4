# MEEM Hub V4 WebApp

نسخة أولى منظمة وقابلة للتطوير إلى Telegram Mini App.

- الإعدادات الشخصية محفوظة في localStorage.
- اللغة: العربية / الفرنسية / الإنجليزية.
- المظهر: فاتح / داكن.
- المواد والأساتذة والبيانات الأكاديمية موجودة حالياً في js/data.js.
- المرحلة التالية: Backend + قاعدة بيانات + حساب Telegram لكل مستخدم + لوحة Admin.
